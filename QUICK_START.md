# 🚀 Quick Start Guide

## ✅ You're All Set!

Your learning tracker is **already running** at:
👉 **http://localhost:5173/**

## 📝 What You Can Do Now

### 1. Open in Browser
```
Open your browser and go to: http://localhost:5173/
```

### 2. Start Tracking Your Progress
- **Click any task card** in the "Backlog" column to start learning
- The card moves to "In Learning" automatically
- **Click the progress ring** (circle) to update your progress (0% → 25% → 50% → 75% → 100%)
- At 100%, tasks automatically move to "Completed"

### 3. Filter by Week
- Use the **sidebar** to filter tasks by week
- Click "Week 1", "Week 2", etc. to see only that week's tasks
- Click "All Tasks" to see everything

### 4. Track Overall Progress
- Check the **header** for your completion rate
- See how many tasks you've completed
